# Year 1 Summer Project
Numerical Orbital Dynamics and Precession Modelling – Year 1 Physics Summer Project

- built an N-body numerical integration code in Python using SciPy differential equation solvers to simulate orbital motion under Newtonian gravity with General Relativistic corrections, modelling gravitational interactions between solar system bodies over long time periods to isolate each planet's contribution to Mercury's perihelion precession rate
- extracted orbital angles (longitude of perihelion) from decades of NASA JPL Horizons ephemeris (time-series) data and used linear regression to fit the precession trend, comparing results with theoretical relativistic predictions within uncertainties
- calculated satellite clock drift rates from competing Special Relativistic and General Relativistic time dilation effects
- presented the findings at a symposium-style event for secondary school students
